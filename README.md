# 高中英文參考詞彙表 Level 4–6 單字測驗工具

🔗 **線上使用：[jaypengx-collab.github.io/English-Vocabulary-Tool](https://jaypengx-collab.github.io/English-Vocabulary-Tool/)**

一個純前端（無需安裝、無需伺服器）的英文單字測驗與複習工具，內建大學入學考試中心（大考中心）
「高中英文參考詞彙表」（108 課綱）Level 4、5、6，共 3,060 個單字。

## 功能

- **單字測驗**：播放預先錄製的高品質單字發音（見下方「單字發音」），聽完後輸入拼字，
  立即核對答案並顯示中文意思，回合結束後列出成績與拼錯的單字清單。每回合預設 80 題，
  組成為 80% 新字／10% 曾經答錯／10% 曾經答對（用來檢驗記憶是否穩固）；若選擇的等級
  範圍字數不足，系統會自動用其他類別的單字補足，且同一回合不會出現重複單字。
- **複習測驗**：自動從「答錯清單」出題（不需要手動整理），再次作答後會顯示這次複習
  的正確率與反應時間變化，並詢問要「保留全部」還是「移除答對的單字」——只有這次確實
  答對的單字才會被移出答錯清單。
- **記憶分數系統**：每個單字都有獨立的作答歷史（次數、對錯、反應時間、一致性、進步
  幅度……），系統會用這些歷史資料估計「這個字記得多熟」，而不是用單一固定的反應時間
  門檻或「反應時間 ÷ 單字長度」這種簡化公式；新字不會因為一次答對就被視為已熟記，
  較長的單字也不會只因為打字本來就比較久而被誤判為不熟。單字狀態分為
  尚未測驗 → 學習中 → 待複習 → 已熟記 四個階段。
- **中文意思**：每個單字都附有中文意思（含詞性），作答後的回饋與回合結束的單字清單都
  可以點擊查看。
- **學習進度**：總覽已練習過／已熟記／學習中／待複習的單字數量、整體正確率、熟記率、
  近期正確率與反應時間趨勢，並依 Level 4/5/6 分別呈現進度；也可依狀態或關鍵字篩選、
  查看每個單字的詳細作答紀錄。
- 可自由勾選要練習的等級（4、5、6 可複選）、選擇語音與語速、設定每回合題數。
- 所有學習紀錄儲存在瀏覽器 `localStorage`，重新整理或關閉分頁不會遺失進度（同一台裝置
  / 同一個瀏覽器）；舊版資料會自動轉換成新格式，不會被清除。

## 架構

- `logic.js`：不依賴 DOM、可獨立單元測試的核心邏輯——記憶分數計算、80/10/10 選題邏輯、
  進度統計、資料格式轉換（migration）。
- `app.js`：畫面渲染、事件處理、`localStorage` 讀寫、語音播放，呼叫 `logic.js` 提供的函式。
- `tests/logic.test.js`：涵蓋計分、冷啟動行為、單字長度公平性、選題比例與備援、複習測驗、
  資料轉換等情境，執行方式：`npm test`（需要 Node.js）。

## 單字發音

瀏覽器內建的語音合成（Web Speech API）音質好壞完全取決於使用者的作業系統/瀏覽器裝了
哪些語音，常常很機械、不同裝置聽起來也不一致。因此每個單字的發音都改成**事先錄製**：
用開源工具 [`edge-tts`](https://github.com/rany2/edge-tts)（呼叫 Microsoft Edge
線上語音服務的神經網路語音，不需要 API 金鑰）為全部 3,060 個單字各產生一個 mp3 檔，
存在 `data/audio/<單字小寫>.mp3`，網頁直接播放這些檔案；只有在檔案載入失敗時（例如
之後新增單字但還沒重新產生音檔）才會退回使用瀏覽器的語音合成。

重新產生音檔（例如換了語音、或 `data/vocab.json` 增加了新單字）：

```bash
pip install edge-tts
python3 scripts/generate_audio.py        # 已存在的檔案會自動略過，可安全中斷重跑
```

（大考中心公布的詞彙表本身只有文字，並未附官方發音音檔——市面上的單字 App
多半也是自行外包錄音或使用 TTS，因此這裡選擇免費、可重現產出的 TTS 方案。）

## 使用方式

直接開啟 [線上網址](https://jaypengx-collab.github.io/English-Vocabulary-Tool/) 即可，無需登入、
無需安裝任何東西。建議使用 Chrome、Edge 或 Safari 以獲得較自然的英文語音。

## 本機開發

因為頁面用 `fetch` 讀取 `data/vocab.json`，直接用瀏覽器開啟 `index.html`（`file://`）會被
瀏覽器的 CORS 規則擋下，請用簡單的本機伺服器啟動，例如：

```bash
python3 -m http.server 8000
# 然後開啟 http://localhost:8000
```

執行測試（需要 Node.js 18+）：

```bash
npm test
```

## 資料來源

單字、詞性資料整理自大學入學考試中心公布之《高中英文參考詞彙表》（108 課綱），
Level 4–6 共 3,060 字；中文意思取自開源英漢字典 [ECDICT](https://github.com/skywind3000/ECDICT)，
並轉換為繁體中文。
