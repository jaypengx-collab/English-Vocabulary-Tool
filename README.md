# 高中英文參考詞彙表 Level 4–6 練習工具

🔗 **線上使用：[jaypengx-collab.github.io/English-Vocabulary-Tool](https://jaypengx-collab.github.io/English-Vocabulary-Tool/)**

一個純前端（無需安裝、無需伺服器）的英文單字聽力與複習工具，內建大學入學考試中心（大考中心）
「高中英文參考詞彙表」（108 課綱）Level 4、5、6，共 3,060 個單字。

## 功能

- **聽寫練習**：使用瀏覽器內建語音合成（Web Speech API）朗讀單字，聽完後輸入拼字，
  立即核對答案並顯示中文意思，回合結束後列出成績與拼錯的單字清單。
- **複習卡片**：Anki 式間隔複習系統（Leitner box + 間隔重複）。聽發音、猜拼法與意思，
  再顯示答案（含中文意思）並依熟悉程度（忘記了／有點難／記得／很熟悉）安排下次複習
  時間，讓單字隨著多次練習慢慢記牢。
- **答對就降低再出現機率**：答對的單字會被記錄下來，下次複習的間隔隨之拉長；拼錯則
  會重設，很快就會再考一次。
- **反應時間偵測**：聽寫時系統會學習你平常的作答速度（依單字長度換算），如果某題你
  雖然答對了、但想的時間明顯比平常久，代表其實還不夠熟，該字仍會提早再出現，而不是
  直接被視為已熟記。
- **中文意思**：每個單字都附有中文意思（含詞性），複習卡片顯示答案時會一併呈現；
  聽寫與複習回合結束後的單字清單也可以點擊每個單字查看中文意思。
- **學習統計**：總覽已熟記／學習中／尚未學習／待複習的單字數量，並依 Level 4/5/6 分別
  呈現進度，以及目前學到的作答速度基準。
- 可自由勾選要練習的等級（4、5、6 可複選）、選擇語音與語速、設定每回合題數。
- 所有學習紀錄儲存在瀏覽器 `localStorage`，重新整理或關閉分頁不會遺失進度（同一台裝置
  / 同一個瀏覽器）。

## 使用方式

直接開啟 [線上網址](https://jaypengx-collab.github.io/English-Vocabulary-Tool/) 即可，無需登入、
無需安裝任何東西。建議使用 Chrome、Edge 或 Safari 以獲得較自然的英文語音。

## 本機開發

因為頁面用 `fetch` 讀取 `data/vocab.json`，直接用瀏覽器開啟 `index.html`（`file://`）會被
瀏覽器的 CORS 規則擋下，請用簡單的本機伺服器啟動，例如：

```bash
python3 -m http.server 8000
# 然後開啟 http://localhost:8000
```

## 資料來源

單字、詞性資料整理自大學入學考試中心公布之《高中英文參考詞彙表》（108 課綱），
Level 4–6 共 3,060 字；中文意思取自開源英漢字典 [ECDICT](https://github.com/skywind3000/ECDICT)，
並轉換為繁體中文。
